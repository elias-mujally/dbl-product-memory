# DBL Employee AI — Blockers

آخر تحديث مرجعي: **2026-08-19**

## العوائق الحالية الرئيسية

1. Market validation للـAI-driven business execution ما تزال غير مثبتة.
2. Salla developer / partner access لغير السعودي غير محسوم.
3. First meaningful write action غير محسوم.
4. Meta Business / Tech Provider / coexistence readiness غير مكتملة أو غير مثبتة بما يكفي.
5. WhatsApp real Production connection غير موجود بعد؛ الاتصال الحالي test-only.
6. Legacy Cloud Run webhook ما يزال مسارًا تشغيليًا تاريخيًا يحتاج قرار cutover منفصل.
7. Product scope creep خطر دائم؛ لا توسع CRM/ERP/workflow/multi-agent بلا evidence.

## قاعدة

لا تجعل عائق منصة خارجية مثل Meta يمنع اختبار فرضية المنتج الأساسية بوسائل Web/Internal/Wizard-of-Oz إذا أمكن.
